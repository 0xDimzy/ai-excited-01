# The Eye That Launches Light

A make.fun ai-excited-01 entry. The program writes one image to `/output/entry.png`: a gigantic eye in a stormy sky, a rocket of light bursting through its pupil, a tiny city watching below.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
